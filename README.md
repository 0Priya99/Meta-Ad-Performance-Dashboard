Meta Ad Performance Dashboard

Project Overview

The Meta Ad Performance Dashboard is an interactive business intelligence dashboard developed using Microsoft Power BI. It provides detailed insights into advertising performance across Meta platforms (Facebook and Instagram) by analyzing key marketing metrics such as impressions, clicks, engagements, purchases, conversion rates, and budget utilization.

The dashboard helps marketers and business analysts monitor campaign effectiveness, identify audience behavior patterns, and make data-driven decisions to improve advertising performance.

Objectives
Monitor overall ad campaign performance.
Analyze user engagement and conversion metrics.
Track advertising budget utilization.
Compare performance across Facebook and Instagram platforms.
Identify audience demographics and interests.
Visualize geographical distribution of ad impressions.
Support strategic marketing decision-making.
